# ✂️ MAX Booking & Referral Bot

Бот для онлайн-записи клиентов в салон и реферальной программы с начислением и списанием бонусов для платформы **MAX (max.ru)**.

Бот полностью сохраняет и воспроизводит функционал Telegram- и VK-версий с адаптацией под официальный **MAX Bot API**.

---

## 🚀 Стек технологий
- **Python 3.10+** (протестировано на Python 3.14)
- **maxapi 1.x** (официальная асинхронная библиотека для MAX Bot API)
- **SQLite** (режим WAL, пул соединений)
- **python-dotenv**

---

## 📋 Основной функционал
- ✂️ **Онлайн-запись**: быстрая кнопка перехода к виджету онлайн-записи в один клик.
- 📍 **Геолокация и адрес**: отправка адреса, графика работы и прямой ссылки на точку в Яндекс Картах.
- 🧴 **База знаний по уходу**: статьи и советы по укладке и бороде с интерактивным каталогом товаров на Ozon через инлайн-кнопки.
- 🎁 **Реферальная программа**:
  - Персональные ссылки `https://max.ru/<username_бота>?start=ref_<id>` (через `maxapi.utils.deep_linking`), а также поддержка события первого старта `BotStarted.payload` и ввода кода `ref_<id>`.
  - Уведомление реферера в личные сообщения при регистрации друга.
  - Начисление бонуса (300 ₽) после первого подтверждённого визита.
  - Просмотр статистики и баланса бонусов.
- ⚙️ **Админ-панель** (`/admin` или кнопка для админов):
  - Инлайн-интерфейс подтверждения визитов рефералов.
  - Списание бонусов в счёт оплаты с автоматическим уведомлением клиента.
  - Постраничная навигация (пагинация).

---

## ⚙️ Получение токена и настройка бота в MAX

1. Зарегистрируйтесь на портале разработчиков **[MAX Bot API (dev.max.ru)](https://dev.max.ru)** или воспользуйтесь сервисным ботом создания ботов в мессенджере **MAX**.
2. Создайте нового бота, задайте ему имя и `username`.
3. Скопируйте полученный токен бота (`MAX_BOT_TOKEN`).

## 🛠 Установка и запуск

### 1. Создание виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate  # На macOS / Linux
# .venv\Scripts\activate   # На Windows
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Заполните переменные в `.env`:
```env
MAX_BOT_TOKEN=ваш_токен_бота_max
ADMIN_IDS=ваш_max_id
BOOKING_URL=https://mst.link/boris_gafurov/price?cid=vddrm99a3uu0o9cgk508u6uctp
SALON_ADDRESS=Саратов, ул. имени Е.И. Пугачёва, 110
SALON_LATITUDE=51.536988
SALON_LONGITUDE=46.013896
WORK_HOURS=Вторник и суббота: 10:00–19:00
REFERRAL_REWARD_AMOUNT=300
```

> 💡 **Как узнать свой MAX ID**:
> Запустите бота и отправьте ему в сообщения команду `/myid` — бот мгновенно пришлёт ваш цифровой идентификатор в MAX. Добавьте его в `ADMIN_IDS` в `.env`.

### 4. Тестирование
Для запуска модульных и интеграционных тестов:
```bash
python -m unittest tests/test_bot.py
```

### 5. Запуск бота
```bash
python main.py
```

После старта бот автоматически:
1. Инициализирует базу данных SQLite.
2. Зарегистрирует команды в клиенте MAX (`/start`, `/book`, `/location`, `/advice`, `/referral`, `/myid`, `/admin`).
3. Запустит Long Polling приёма обновлений и событий от пользователей.
